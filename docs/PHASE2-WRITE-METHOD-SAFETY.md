# Phase 2 — Write-method safety matrix (admission draft)

> **Superseded interface draft:** do not implement these rows. The active MVP
> removes Arc-source/finality-proof writes, reduces GenLayer to per-match judging,
> and adds configured-operator settlement. Rebuild the safety cards in active
> Phase 1 before contract code.

These are behavior-level rows for the later Arc escrow and GenLayer judge.
Names are provisional until the ABI phase freezes them. A method may not be
implemented while any row is changed or left vague.

## Cross-cutting invariant

Every rejected write must leave canonical phase, bracket/ranking state, and
USDC liabilities unchanged, except for an explicitly allowed non-penalizing
retry/unverifiable record. External API or GenLayer GEN expenses never debit the
tournament escrow. The exact ABI and caller roles remain provisional until the
admission gates close.
